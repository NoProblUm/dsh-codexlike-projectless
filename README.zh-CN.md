# dsh-codexlike-projectless

[English](README.md) | **简体中文**

在 DeepSeek Harness 中先编辑无项目草稿，首次发送时再创建按日期和主题组织的工作目录。保留原生输入框、模型与推理设置、权限、Agent、规划、附件和发送状态机。

**1.0.0** 是单一市场包的正式版本：业务代码与版本限定的运行时适配层一起加载，不改写应用归档或第三方插件文件，不需要外部安装助手。证据和限制见 [运行时适配与验收](docs/适配-DSH-0.2.1-rc.2.md)。

本项目独立维护，采用自己的版本编号，不是 DeepSeek 或 OpenAI 官方项目。包含来自 Jarvis Luk 的 MIT 许可代码，归属说明见 [NOTICE](NOTICE) 和 [LICENSE](LICENSE)。

## 支持范围

首版限定 Windows Desktop **0.2.1-rc.2**、构建 **332895e0f7c9d4dbfb29729f5eb367fa263ff986**。宿主核对原版模块的 SHA-256，客户端检查必要方法和包装归属。相同版本号不代表其他构建也受支持。

适配依赖该构建的内部实现。版本不匹配、旧归档补丁残留或关键方法被其他插件接管时，停止无项目核心流程，并在“设置 → 通用 → 无项目会话”说明原因。不会反复覆盖其他插件的方法或自动安装归档补丁。

Git Graph 等接管新建流程的功能需要对应组合的单独验证；没有安装相关插件的用户不受这一检查影响。不承诺所有插件和加载顺序都兼容。

## 安装、更新与卸载

1. 使用 DSH 插件市场或官方插件管理器安装预构建包 dsh-codexlike-projectless-1.0.0.tgz。
2. 安装后正常退出并重新打开整个 DSH；“等待正常重启”不等于适配已可用。
3. 在“设置 → 通用 → 无项目会话”选择工作区根目录并保存。默认根目录为 ~/Documents/DSH。

日常安装不需要用户安装 Node.js、下载脚本、手动解压、运行 Install.cmd 或改写包管理配置。市场和官方管理器负责安装与更新。

停用或卸载释放本插件拥有的运行时改动，保留已创建的会话、目录和用户产物。当前页面内未发送的草稿不保证在停用后恢复，请先自行保存。已提交或结果不明的操作不会因卸载被重发或回收。

### 从 0.1.x 归档补丁安装迁移

先停用旧插件，使用旧版安装记录对应的恢复工具明确恢复原版；核对恢复后的构建与归档，再通过市场安装新版。如果依赖仍指向安装器目录中的 link: 副本，通过管理器移除旧副本后重新安装。不要将新适配层叠加在旧归档补丁上。

旧恢复工具可能还原备份时的 profile 配置，使用前核对备份和后续配置改动。新版不会静默恢复归档或替用户选择旧备份。迁移保留会话和目录。历史安装工具留在仓库中作为基线，不是本版本的安装入口。

## 使用行为

- 明确选择“无项目”后，首次发送前不创建真实 Session、Workspace 或任务目录。文件附件留在原生注册表中，真实会话建立后才上传；图片沿用原生编码与提交。
- 首发冻结输入和设置，通过原生标题 provider 和回退机制准备主题，再原子创建 根目录/YYYY-MM-DD/主题。重名追加 _2、_3，不接管已有目录。
- 消息接收后注销临时 Workspace，保留会话、cwd、目录和历史。注销失败时保留已接收结果并报告错误。
- 同一页面内切换项目可恢复最近的空白编辑页；显式新建打开另一份空白编辑页，不带入旧正文和附件。
- 草稿只在当前客户端页面内存活。关闭、刷新、重启或停用后不保证恢复文本、设置和附件。项目选择仍可跨重启保留。
- 启动时有效的原生历史会话优先。未保存过项目选择时，保留原生默认项目初始化；保存无项目选择且原生目标为空白或无效时，进入新的本地草稿。
- 创建失败或明确拒绝时，按本次所有权回收可安全删除的空目录，保留可重试输入。所选 Agent 不支持设置时在发送前报错，不悄悄忽略设置。
- 结果不明时保留输入与资源，锁住重复首发，按本次原生请求标识核对持久消息。刷新不会自动清扫此前结果不明的资源，也不会自动重发。

项目名称和箭头打开菜单；选中项目时，悬停或键盘聚焦显示左侧 ×，用于切换到无项目，不更改历史会话的项目归属或 cwd。
