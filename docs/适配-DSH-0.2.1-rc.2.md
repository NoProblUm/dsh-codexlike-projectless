# 1.0.0：DSH 0.2.1-rc.2 Windows 适配与验证记录

日期：2026-10-17。用户确认已重新真实测试通过，并授权以 1.0.0 正式发布到 GitHub。该确认属于用户手工复测结果，本次发布准备不将其表述为重新执行了全部 Desktop 自动验收。

先前隔离验收的市场 rc1→rc2 原位更新曾返回 `already-installed`，该轮后续重启、停用、卸载与重装因此停止。此历史失败没有删除，也不计为自动验收通过。正式发布依据为用户后续手工复测确认、归档候选源码和本次重新执行的自动检查。

## 基线与目标

当前增量基于完整工作树中的 1.0.0-rc1，并非旧 Git HEAD。实施前保留了 122 个已跟踪及未跟踪文件的源码快照。原冻结 rc1 包 SHA-256 为 `c2480b55ca45e63034702334c1ae076f0ab6daef7fc5eaa2e67a043f57ee5179`，未覆盖或重打。源码基线实际支持 0.2.0-rc.2；工作区既有升级实验属于 0.2.1-rc.1，不作为本轮通过证据。

支持范围仅为从官方 Windows x64 安装包提取的 0.2.1-rc.2：

- dshBuildCommit：`332895e0f7c9d4dbfb29729f5eb367fa263ff986`；dshBuildDirty=false。
- app.asar SHA-256：`47874618bf5b3011fcaac10cd4c85f69da333e70d4f99b921207c78d0999512a`。
- 适配标识：`desktop-0.2.1-rc.2-332895e0-runtime-2`。
- 官方安装包 SHA-512、大小与官方 nightly 清单一致，Authenticode 签名有效。

工作区 UI、会话 UI、会话控制器、标题、Client 文件上传、远程访问六个官方 npm 包的 rc.1/rc.2 发布 JavaScript 与 TypeScript 声明重新比较后均一致。该结果不等于 Desktop 整体兼容通过；本适配另外采集原版归档模块指纹并在独立 profile 运行实际场景。

## 相对插件 rc1 的改动

- 包版本及 Host/Client 适配标识更新，engines.dsh 和全部 DSH 开发依赖精确限定到 0.2.1-rc.2。无旧宿主兼容分支。
- 无显式 Workspace 的新建请求进入本地草稿，保留 prompt、clearPreviousDraft、agentPreset；显式 Workspace 委托原生流程。输入初始化调用公开接口，处理 applied、preserved、blocked。
- 普通文件保留原生浏览器 File 注册表。取消占位 receiptId，以本地待上传状态记录；展示边界仅调整原生文件提交可用性，不提供成功凭证。真实 Session 建立后原生上传取得凭证，失败保留输入，重试在新 Session 重新上传。
- 从宿主目录读取模型与推理档位；首发冻结用户选择并重新确认目录可用性，不静默换模型。Search/Fetch 设置不变。
- 首发复用原生标题 provider、fallback、日志和发送；预生成标题消耗后跳过该次首次自动生成，后续标题正常更新，不重命名目录。
- 已接收但临时 Workspace 注销失败时保留真实会话和产物，提供独立注销重试；unknown 保留资源并禁止自动重发。
- 状态附带原因、包版本、适配、完整构建提交及缺失能力。包装记录实例、原方法、安装方法和代次；重复激活复用现有实例，释放只恢复仍属于本插件的方法。

## 证据层级

自动门槛为类型检查、单元回归、构建和包内容检查。Desktop 场景以独立 profile 的真实原生编辑器、菜单、快捷键、附件服务、官方管理器及市场路由执行；确定性 llm/stream 测试用于请求次数和故障注入，不能代替外部推理成功。

已执行的核心场景包括带参数新建、原生输入初始化、文件/PNG 重连保留、无伪造凭证的延迟上传、规划首发、后台切换不抢导航、精确 requestId 响应丢失对账、unknown 刷新保护、模型目录不可用、创建失败、明确拒绝、上传失败重试、注销失败独立重试，以及准备/提交阶段取消。

最终外部模型实测、冻结包校验、市场安装/更新/重启/卸载及完整性结果分别写入交付目录的分层验收报告；请以对应包 SHA-256 与该报告关联，不把旧宿主、旧构建或旧包记录混入。

## 使用与边界

通过市场或官方管理器安装正式包后正常重启。已有旧 app.asar 补丁必须先按其安装记录恢复原版，不可叠加。草稿仅在当前 Client 页面内存存活，不承诺刷新、关闭、重启、停用后的内容恢复。不确定请求在刷新后保留真实资源，不因此授权重发或删除。

未验证其他 Desktop 构建、操作系统或第三方接管组合。冲突检查仅涉及实际占用的原生路径，不要求安装 Git Graph，不修改第三方文件，也不争抢方法。故障注入和模型 fixture 仅在隔离 profile，不进入市场包。
