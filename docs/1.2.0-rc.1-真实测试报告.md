## 界面与已知限制

此前 48 张截图覆盖项目 blank/已发送页 × 插件开/关 × 浅深主题 × 1280/800 宽度 × 1/1.25/1.5 缩放；原生输入区几何及图标对照记录为 `matrix-result.json`。本轮新增相同主题、宽度及缩放组合的 12 张无项目草稿截图，见 `output/rc3-realtest-20261027/draft-matrix.json`。设置页、重启提示和代表性窄屏截图已目视检查，未声称人工逐张检查全部截图。

800 宽、150% 缩放时，原生 hero 标题/部分内容存在裁剪；插件关闭的原生对照也相同。通过的是草稿内容保留、主题/视口断言及指定几何检查，不能写成整个界面完全无遮挡。

**Git Graph 0.4.6 组合不在本候选支持范围。** 此前在 rc.3 单独启用 Graph 时，真实 worktree 能创建，但带 prompt/replace 的 startSession 没有初始化正文；关闭 Graph 的原生对照能填入。`graph-alone-worktree.json`、`graph-control.json` 保留该限制。未将旧宿主的双加载顺序成功结果当作 rc.3 组合通过，也未修改第三方插件或放宽未知包装检查。

未覆盖的扩展项包括：每一种 Agent 预设定义修改后的装配语义、所有引用来源的发送序列化、卸载失败等全故障排列、未知宿主/旧补丁在真实 Desktop 中的逐一变体。它们不计入已通过项；本结论限于表列路径和固定构建，不扩大到任意宿主、第三方插件或外部服务。

## 复现、原始失败与清理

本机复现入口均从仓库根运行。隔离应用和模型 fixture 的准备办法沿用 `experiments/runtime-acceptance/README.md`，本轮专用启动器为 `output/rc3-baseline-20261027/layout.mjs`，绑定上面的 rc.3 哈希和端口。它与旧的 `scripts/probe-runtime-desktop.mjs` 目标不同，不可混用。

```powershell
node output/rc3-baseline-20261027/layout.mjs restart output/runtime-candidate-rc3-clean
node output/rc3-realtest-20261027/remaining.mjs
node output/rc3-realtest-20261027/extended.mjs
node output/rc3-realtest-20261027/visual.mjs
```

场景会改变隔离 profile；visual 最后触发热启用状态，随后需正常重启。运行期草稿和故障注入有前置状态，不能盲目把脚本串成任意顺序。Playwright 依赖来自仓库既有 `.npm-cache`，入口保留其确切本机路径；独立复现需准备相同依赖。

早期菜单截图超时、未悬停便点击关闭图标、requestId 读取层级错误、设置初始加载未完成及误选不确定历史会话的测试脚本问题均已排查。最终成功记录与最初失败记录分开保留，没有因此修改产品代码。单独执行 submission-state 时的 `extended.json` 覆盖了首次汇总文件，因此其他扩展项读取 `extended-first-run.json`，不将其中旧的失败断言算作最终结果。

最后测试主进程已通过正常退出结束，并校验不再存在；`dsh://` 协议关联恢复并核验。设置根目录已恢复。未改日常 profile、安装目录或第三方插件，未提交或发布。工作树原有 `src/client/session.ts:414` 的 EOF 空行使全树 `git diff --check` 报告既有问题，本轮没有修改该文件。
