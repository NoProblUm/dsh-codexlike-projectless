# DSH Codexlike Projectless 0.1.0 初版验证

验证日期：2026-10-03。

## 独立身份

- 仓库目标名称、npm 包名和 Cordis 插件 ID：dsh-codexlike-projectless。
- 独立初版版本号：0.1.0。
- Host/Client RPC、插槽、语言包、浏览器选择记录、设置文件和诊断日志采用独立命名空间。
- 安装使用本项目自己的插件包，不要求安装上游插件；启用旧插件时安装器拒绝继续。
- 保留原始 MIT LICENSE，NOTICE 记录源码来源。旧版本仅出现在历史证据、迁移说明和恢复兼容中。

## 本次已验证

- TypeScript 类型检查通过。
- 59 项自动化测试全部通过，包括目录回收、链接替换防护、发送状态和草稿切换。目录安全测试需要正常 Windows 权限；沙箱执行出现 EPERM，随后在正常权限下通过。
- Host/Client 构建通过，新构建不含旧插件 ID。
- npm 包名、版本、锁文件、插件注册和原生补丁清单一致。
- 插件包包含 Host/Client、双语 README、NOTICE 与 LICENSE，不包含 DSH archive、用户 profile、node_modules 或本机测试产物。
- 安装和恢复脚本通过 PowerShell 语法解析。
- 使用原版备份重新生成 DSH Desktop 0.2.0-rc.2 的五处原生补丁，补丁后的 JavaScript 语法检查通过。
- LICENSE 与仓库初始提交逐字一致。
