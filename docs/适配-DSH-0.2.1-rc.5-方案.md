# DSH rc.5 适配执行约定

日期：2026-10-31。经讨论确定：从正式 1.2.0 创建独立工作树，按官方 Windows rc.5 发布物做最小适配，候选核心项通过后交付本地 1.3.0 正式包。外部发布和日常安装升级另行授权。

1. 冻结正式 tag、官方更新清单、安装包签名和实际 Desktop 构建身份；比较七模块、npm 声明、导出及调用点，不以公开源码 tag 替代构建号。
2. 只修改实际失配点，保留精确身份/指纹和未知包装拒绝，不增加公开 RPC、配置或多构建支持；受控负向测试与真实 Desktop 测试分层报告。
3. 隔离 profile 分组验证草稿零资源、唯一首发、控件/附件保留、标题、故障对账、清理、思考和 UI 对照、官方管理器生命周期，以及 rc.3 + 1.2.0 升级。未知结果禁止重发；明确拒绝允许保留已创建的 Session，清理重试不得重发。
4. 首发、历史、身份保护和资源安全任一核心项失败、未测或受阻，禁止提升。非阻断原生 UI 问题需保留开关对照后作为限制记录。
5. 冻结候选，核对实际安装字节；本地提升仅允许预期版本/文档/构建映射差异，再做自动检查和正式包安装、重启、首发冒烟。退出测试进程、核对归档并恢复测试改变的协议关联。

实施事实与局限见 [1.3.0 验收报告](1.3.0-验收报告.md)；正式交付结果见 `output/release-1.3.0/verification.json`。不把本约定中的通过条件当成已执行证据。
