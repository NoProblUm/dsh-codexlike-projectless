# 1.4.0 验证报告

适用宿主为 Windows x64 DSH Desktop 0.2.2-rc.3，构建 `6b729fedde0c8fd03af7afdf5a711aa64fe87c3b`，`dirty=false`。验证使用的宿主程序 Authenticode 签名有效，七个原版模块均通过指纹核对。宿主归档 SHA-256 为 `14cfd81c9135bf0afb89417543c94f9ecfe09266574452a9b106890c698725ae`。

## 本版验证

- 自动化检查覆盖宿主兼容边界、首发确认与失败处理、图片预上传与取消，以及两条草稿队列的初始化。类型检查、91 项测试与构建通过。
- 在隔离 Desktop 验证了无项目输入框、普通项目侧栏新建、鼠标与键盘恢复草稿，以及一次使用本地测试模型的文本首发。
- 对照原生项目行检查了“未分组”按钮的静止、悬停和鼠标移出状态，尺寸及右侧间距一致。Tab 聚焦时按钮可见，Enter 可以恢复草稿。正式版的运行代码与最终候选版仅有插件版本号差异。

## 安装与验证范围

用 `SHA256SUMS` 核对下载的 `.tgz`，再通过官方插件管理器导入并完整退出、重新打开 DSH。进入 **设置 → 通用 → 无项目会话**，检查运行时状态为“已就绪”。

真实 Desktop 验证采用隔离配置与本地测试模型。外部模型、宿主安装程序覆盖升级、旧配置迁移和第三方插件组合未纳入本版的自动化或隔离验证。
