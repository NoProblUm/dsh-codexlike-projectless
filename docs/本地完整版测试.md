## 边界

草稿期没有执行目录，所以目录文件检索和需要真实 Agent 的命令在首次消息之后使用。草稿期提供权限与规划命令、原生模型选择和文件选择；发送后恢复全部原生会话能力。浏览器草稿正文与附件不跨刷新保存。

原生补丁限定当前版本与原始 hash，DSH 更新会覆盖或改变接入点；不能宣称任意新版本兼容。遇到通信不确定结果会保留资源并阻止自动重发，等待原生状态确认，避免重复消息。

隔离环境仍有 Claude 皮肤原有字体资源 404，这属于字体加载，未影响上述交互验证；没有因此修改皮肤文件。未逐一验证日常 profile 中全部第三方插件。
