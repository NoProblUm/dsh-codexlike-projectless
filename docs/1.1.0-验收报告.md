## 最终行为与实现范围

新建入口在原导航实例上管理可配置描述符，仅接纳与已验证 Git Graph 0.4.6 完整路由函数匹配的包装。调用隔离前经现有官方插件管理器核对包名、启用状态和 0.4.6 版本，并检查 Workspace 能力；未知包装仍拒绝。

无项目先由本地草稿处理，不读 Git 配置，不进入 worktree 流程。项目请求将已识别路由重绑定为每次请求独立的终端闭包，最终原生 startSession 接收这一操作的完整 StartSessionOptions。各操作不共享“下一次参数”变量；沿用 Git Graph 的隔离开关、重复路由抑制、worktree、失败回退及回滚行为。此固定路由来自 Apache-2.0 的上游实现，改动和许可见 THIRD_PARTY_NOTICES.md。未修改 Git Graph 安装文件或宿主归档。

侧栏在 sidebar.workspaces 组件容器内捕获未分组行的新建按钮激活，以原生 data-row-key 和本地化按钮语义识别，不匹配中文显示文字。鼠标、Enter 和 Space 产生的原生 click 走同一路径。优先恢复最近仍未发送的草稿；当前已显示时不重新导航；最新草稿发送后可回退到仍存活的较早草稿。全局新建仍显式创建新的本地编辑页。

移除隐藏 heroWorkspaceRow 的规则和输入框前的自绘项目/模式栏。项目按钮、Agent 栏、侧栏气泡、输入框及其图标使用宿主原组件；“无项目”菜单项也使用宿主图标。新增关闭动作用宿主 IconCloseOutlineRegular 和独立可聚焦按钮，经 React Portal 补充到原生行，不嵌套按钮、不移动原生 DOM。已发送页不增加项目栏；临时 Workspace 注销重试为单独状态操作。

不改变公开 Host RPC 或原生 StartSessionOptions。草稿正文、附件、编辑设置仍仅保存在当前客户端内存中，不增加刷新、退出、重启持久化。
